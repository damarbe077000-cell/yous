# YOUSIF UNIVERSITY OS
PWA عربي RTL يعمل دون إنترنت (IndexedDB + Service Worker). لا خادم ولا مفاتيح.
## التشغيل
ارفع المجلد كاملاً على GitHub Pages (أو أي استضافة HTTPS) وافتح index.html. الـ Service Worker يحتاج HTTPS أو localhost.
محلياً: `python -m http.server 8000` ثم افتح localhost:8000
## التثبيت على Android
Chrome ← القائمة ⋮ ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
## الاختبار
`node tests/test.js`
## منفّذ فعلياً
لوحة التحكم، المواد، الجدول مع منع التعارض، الواجبات، الامتحانات، الملاحظات مع بحث، Pomodoro مع رسم بياني وStreak، أدوات الحساب، **تعديل العناصر**، **مساعد ذكي** (10 مهام، مزود API قابل للتغيير OpenAI/Anthropic، رفع TXT، حفظ الناتج كملاحظة، وضع محلي للبطاقات والفراغات)، **مكتبة علمية** (10 مجالات + مصادرك)، نسخ احتياطي، وضع ليلي، عمل دون إنترنت.
## ملاحظة أمنية
مفتاح API يُخزَّن محلياً في جهازك فقط ويُرسل للمزود مباشرة. لاستخدام مفتاح سري حقيقي لعدة مستخدمين يلزم خادم وسيط.
## غير منفّذ (يحتاج خدمة أو مرحلة لاحقة)
قراءة PDF والصور داخل المساعد (يحتاج مكتبة/مزود)، ذكر رقم الصفحة، الإشعارات الفعلية قبل المحاضرة، تسجيل الدخول والمزامنة السحابية، حاسبة علمية كاملة وأدوات الكهرباء والشبكات.
